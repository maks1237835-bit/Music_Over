# Music Over — Lyrics Overlay

Окно поверх всех окон с текстом песни, которая играет в **Яндекс Музыке**
(приложение для Windows): строчка за строчкой, в такт музыке.
На паузе окно прячется, когда музыка снова играет — появляется.

## Скачать

**[Последняя версия →](https://github.com/maks1237835-bit/Music_Over/releases/latest)**
— файл `LyricsOverlay-Setup-<версия>.exe`.

## Установка

1. Запусти скачанный `LyricsOverlay-Setup-….exe`.
2. Если появится синее окно «Windows защитил ваш компьютер» — нажми
   **«Подробнее» → «Выполнить в любом случае»**. Так бывает со всеми программами
   без платной цифровой подписи.
3. Нажми «Да» — программа установится, появится ярлык на рабочем столе.
   Права администратора не нужны.

## Как пользоваться

- Включи музыку в Яндекс Музыке — текст появится сам.
- **Alt+8** — настройки: шрифт, цвета, размер, положение, горячие клавиши.
- Зажми **Ctrl** — окно можно двигать мышью и тянуть за край.
- Значок ♪ возле часов — меню и выход.
- Текст отстаёт или спешит — в настройках есть сдвиг тайминга.

## Обновления

Программа сама проверяет новые версии и предлагает обновиться —
скачивать установщик заново не нужно. Настройки при обновлении сохраняются.

## Откуда тексты

С сайта [LRCLIB](https://lrclib.net) и, по желанию, из своей Яндекс Музыки
(Alt+8 → «Тексты из Яндекс Музыки», нужен личный токен — никому его не отправляй).
Тексты песен в этом репозитории не хранятся.

## Удаление

Параметры Windows → Приложения → Lyrics Overlay → Удалить.
